# Ziyi Liu

Portfolio website for Ziyi Liu, featuring choreography, performance, research, teaching, and her CV.

## Website

Published with GitHub Pages from the `main` branch, using the repository root.

## Editing

The seven HTML files contain the page content. `styles.css` and `reference-layout.css` control the appearance. `script.js` contains the menu behavior and performance details. `assets/` contains photographs, fonts, and the downloadable CV. All page and asset links are relative, so the website also works within a GitHub Pages project path.

Open `index.html` to preview locally. Video playback requires an internet connection.

Images document the performances linked in the portfolio; source information is recorded in `asset-sources.json`. Font licenses are included in `assets/fonts/`.
